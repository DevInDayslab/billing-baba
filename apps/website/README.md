# Billing Baba Website

Official public website for Billing Baba — marketing pages, landing site, and web utilities including the collaboration invite flow.

## Stack

- React + Vite + TypeScript
- Tailwind CSS v4
- TanStack Query
- React Router
- Sass (marketing styles migrated from legacy CRA site)

## Development

```bash
cd apps/website
bun install
bun run dev
```

Runs on http://localhost:5173 and proxies `/api` to the API on port 3000.

## Environment

Copy `.env.example` to `.env`:

- `VITE_API_BASE_URL` — API base URL (default `http://localhost:3000`)

## Routes

| Route | Page |
|-------|------|
| `/` | Landing page |
| `/features` | Redirects to `/#features` on home |
| `/pricing` | Pricing plans |
| `/download` | App download |
| `/contact` | Contact information |
| `/privacy`, `/terms`, `/support` | Coming soon (CRA placeholder) |
| `/reset-password`, `/verify-email` | Coming soon |
| `/invite/:token` | Invitation view + accept/reject |
| `/invite/:token/accepted` | Success + deep link |
| `/invite/:token/rejected` | Rejection confirmation |

Invitation URLs are generated by the API as `https://billingbaba.com/invite/{token}`.

Deep link on accept: `billingbaba://invite/{token}`

## Migration notes

Marketing content was migrated from `apps/BillingBaba-website` (legacy CRA). The full POS web app was **not** migrated — that functionality lives in the Flutter client (`apps/client`).

Static assets live in `public/assets/`. Landing SVG icons are in `src/assets/landing/`.

## Deployment

Deployed at **https://billingbaba.com** — all public web routes are served from this app.
