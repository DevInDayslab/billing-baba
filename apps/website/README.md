# Billing Baba Website

Official public website for Billing Baba — landing, marketing, and web utilities including the collaboration invite flow.

## Stack

- React + Vite + TypeScript
- Tailwind CSS v4
- TanStack Query
- React Router

## Development

```bash
cd apps/website
bun install
bun run dev
```

Runs on http://localhost:5173 and proxies `/api` to the API on port 3000.

## Environment

Copy `.env.example` to `.env`:

- `VITE_API_BASE_URL` — collaboration API base (default `/api/v1/collaboration`)
- `VITE_APP_DOWNLOAD_URL` — download page when deep link fails (default `https://billingbaba.com/download`)

## Routes

| Route | Status |
|-------|--------|
| `/` | Coming soon (home) |
| `/pricing`, `/features`, `/download`, `/privacy`, `/terms`, `/support`, `/contact` | Coming soon |
| `/reset-password`, `/verify-email` | Coming soon |
| `/invite/:token` | Invitation view + accept/reject |
| `/invite/:token/accepted` | Success + deep link |
| `/invite/:token/rejected` | Rejection confirmation |

Invitation URLs are generated by the API as `https://billingbaba.com/invite/{token}`.

Deep link on accept: `billingbaba://invite/{token}`

## Deployment

Deployed at **https://billingbaba.com** — all public web routes are served from this app.
